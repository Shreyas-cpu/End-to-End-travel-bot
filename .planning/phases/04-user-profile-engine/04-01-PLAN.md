<objective>
Implement a persistent Markdown User Profile engine to capture passenger interests and inject personalized context into recommendations.

Purpose: Repeated bookings should remember traveler preferences (e.g. airline loyalty, dietary, pool/spa needs) without repetitive questions.
Output: userProfileService, Markdown profile storage pipeline, and LLM context injector.
</objective>

<tasks>

  <files>src/services/userProfileService.ts</files>

    - Storage path: `data/profiles/{userId}.md`
    - Profile structure: Name, Traveler Type, Airline Preferences, Hotel Preferences (amenities, location), Budget Sensitivity, Past Destinations.
    - `getProfile(userId: string): Promise<string>`
    - `updateProfile(userId: string, preferences: Partial<UserProfile>): Promise<void>`
    - Create default profile template if file does not exist.
  </action>

</task>
